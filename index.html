💡 친절한 프론트엔드 코드 설명 (5줄 요약)

  1. 1. 구조(HTML): fieldset과 legend로 종이 노트의 칸을 만들고 모든 입력칸에 명확한 label과 id를 연결했습니다.
  2. 2. 스타일(CSS): 베이지와 크림 화이트, 원목 갈색으로 아늑한 종이 질감과 상단 스프링 구멍 장식을 연출했습니다.
  3. 3. 동적 UI: 요일별 select 선택 시 '알바'일 때만 시급과 시간 입력창이 자연스럽게 나타나고 숨겨집니다.
  4. 4. 유효성 검사: 계산 버튼 클릭 시 이름, 요일 선택 여부, 시급·시간 입력을 단계별로 엄격하게 점검합니다.
  5. 5. 주급 계산식: 총 15시간 이상 근무 시 법정 주휴수당(최대 40시간 비례)을 정확히 합산해 예쁜 결과 카드로 안내합니다.
